# Hearts of Iron IV — Türkçe Yama

Hearts of Iron IV için geliştirilen, oyunu Türkçe olarak deneyimlemeyi amaçlayan topluluk odaklı bir yerelleştirme projesidir.

## 📖 Proje Hakkında

Bu proje, Hearts of Iron IV'ün oyun içi metinlerini Türkçeye kazandırmayı ve Türkçe konuşan oyuncular için daha erişilebilir bir oyun deneyimi sunmayı hedeflemektedir.

Çevirilerde tarihsel terminoloji, anlam bütünlüğü ve Türkçenin doğal kullanımı ön planda tutulmaktadır.

## 📥 Kurulum

1. GitHub üzerinden projenin güncel sürümünü indirin.
2. İndirdiğiniz dosyaları Hearts of Iron IV'ün mod klasörüne yerleştirin.
3. Paradox Launcher üzerinden Türkçe Yamayı etkinleştirin.
4. Oyunu başlatın.

## 🔄 Güncellemeler

Proje kapsamında çeviri eksiklikleri, yazım hataları ve yeni oyun sürümleriyle ortaya çıkan uyumsuzluklar giderilmeye çalışılmaktadır.

Güncellemeler GitHub üzerinden yayımlanacaktır.
